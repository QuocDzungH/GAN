# Generative Adversarial Networks (GANs) Implementation

Thư viện tổng hợp và triển khai các mô hình **Mạng đối kháng tạo sinh (GAN)** từ cơ bản đến nâng cao trên tập dữ liệu **MNIST** -tập hợp các chữ số viết tay từ 0 đến 9

---

## 📌 Danh sách các Notebook

1. **`1.Conversion_L2.ipynb`**: Tái tạo và chuyển đổi hình ảnh dựa trên hàm tổn thất $L_2$ (Baseline / L2 Loss Reconstruction).
2. **`2.GAN.ipynb`**: Triển khai mô hình **Vanilla GAN** cơ bản (sử dụng các lớp Fully Connected).
3. **`3.DCGAN.ipynb`**: Triển khai mô hình **Deep Convolutional GAN (DCGAN)** tích hợp các lớp Convolutional và Transposed Convolutional.
4. **`4.Conditional_GAN.ipynb`**: Triển khai mô hình **Conditional GAN (cGAN)** cho phép sinh ảnh theo nhãn lớp (Class labels).
5. **`5.Conditional_DCGAN.ipynb`**: Kết hợp giữa DCGAN và cGAN (**cDCGAN**), sinh ảnh chất lượng cao theo điều kiện nhãn.
